    How to use

    Click an item in the search list: add it to the current tab (needing the selected upgrade, if ticked).
    Click an upgrade in the tree: select it. Drag one onto another: it then requires that one (drag onto empty space: no requirements).
    Right-drag or middle-drag: pan. Wheel: zoom.
    Del delete the selected upgrade · Ctrl+Z undo · Esc cancel.

    The frame colour shows the dearest anchor it costs: stable, unstable, corrupted. Lines only show requirements in the same tab.

    The tree is laid out on a grid like the game (and Pacific Drive): what an item leads to sits in the cells around it, carrying on outward. Separate trees keep the order of the list: use Move up/down to reorder them.

    A recipe Survival unlocks from the start is locked while it's in the tree (it has to be unlocked here); take it out and it's free again.

    Your work is kept in this browser between visits. After saving, clear the game's Cache folder before launching. Old saves keep what they already unlocked.
